RESOLUCIÓN DE EJERCICIOS: ERRORES Y MEDICIONES

1. DATOS
   Mediciones de una longitud:

| Medición N.° | Medida (cm) |
| :----------: | :---------: |
|      1       |    2,83     |
|      2       |    2,85     |
|      3       |    2,87     |
|      4       |    2,84     |
|      5       |    2,86     |
|      6       |    2,84     |
|      7       |    2,86     |

2. DETERMINAR
   a) Valor probable (media aritmética)
   X̄ = (2,83 + 2,85 + 2,87 + 2,84 + 2,86 + 2,84 + 2,86) / 7
   X̄ = 19,95 / 7 = 2,85 cm

b) Error relativo y porcentual de la 3.ª y 4.ª medición
Valor probable: X̄ = 2,85 cm

3.ª medición: X = 2,87 cm
ΔX = |2,87 − 2,85| = 0,02 cm
ε = ΔX / X̄ = 0,02 / 2,85 = 0,0070
ε% = 0,70%

4.ª medición: X = 2,84 cm
ΔX = |2,84 − 2,85| = 0,01 cm
ε = ΔX / X̄ = 0,01 / 2,85 = 0,0035
ε% = 0,35%

3. LONGITUD 3,2 ± 0,01
   a) Error relativo
   ε = ΔX / X = 0,01 / 3,2 = 0,0031

b) Error porcentual
ε% = 0,0031 × 100 = 0,31%

4. ERROR PORCENTUAL 4%, VALOR PROBABLE 1,85 m
   a) Error relativo
   ε = ε% / 100 = 0,04

b) Error absoluto
ΔX = ε × X = 0,04 × 1,85 = 0,074 m

5. AMPERÍMETRO: MEDIDA 350 mA, PATRÓN 335 mA
   Error absoluto
   ΔX = |350 − 335| = 15 mA

Error relativo (respecto al valor patrón)
ε = ΔX / X_verdadero = 15 / 335 = 0,0448
ε% = 4,48%

6. CLASE DEL VOLTÍMETRO
   Lecturas: verificar 0·50·100·200 V | patrón 0·49·98·197 V
   Errores absolutos: |50−49| = 1 V · |100−98| = 2 V · |200−197| = 3 V
   Error máximo: ΔX_máx = 3 V
   Alcance máximo de escala: 200 V
   Clase = (ΔX_máx / alcance) × 100 = (3 / 200) × 100 = 1,5
   Clase = 1,5

7. VATÍMETRO DE CLASE 2,5, CAMPO 0–500 W
   Error máximo = (clase × alcance) / 100 = (2,5 × 500) / 100 = 12,5 W

RESPONDER

1. ¿Por qué se producen errores al efectuar mediciones?
   Los errores son inherentes al acto mismo de medir. Se producen porque ningún instrumento
   es perfecto ni puede reproducir una magnitud con exactitud absoluta: existen limitaciones
   de calibración, de resolución y de lectura del instrumento, perturbaciones del sistema
   medido por el propio instrumento (error de carga), condiciones ambientales (temperatura,
   humedad), y variaciones del observador (paralaje, criterio de lectura). Además, hay
   perturbaciones aleatorias impredecibles (ruido térmico, vibraciones) que hacen que cada
   lectura difiera ligeramente de la anterior. Por ello, toda medición lleva asociada una
   incertidumbre que debe cuantificarse.

2. ¿Qué se entiende por valor verdadero o probable de una medición?
   El valor verdadero es el valor real e ideal de la magnitud, que en la práctica nunca puede
   conocerse con exactitud absoluta. El valor probable es la mejor estimación de ese valor
   verdadero, obtenida como la media aritmética de un conjunto de mediciones repetidas
   realizadas en las mismas condiciones; al promediar, los errores aleatorios tienden a
   compensarse y el resultado se aproxima al valor verdadero. Se expresa como X = X̄ ± ΔX,
   indicando el intervalo dentro del cual se espera que se encuentre el valor verdadero.
